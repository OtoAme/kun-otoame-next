[求助区](/help)是用户之间互相解答问题的地方。游戏打不开、压缩包解不开、找不到某个补丁，或者想找一部忘了名字的游戏，都可以在这里发帖，由其他用户回答。

> **求助区由社区自愿回答，不保证有人回应。** 网站管理员和资源发布者没有义务回答求助。下面几类问题有更合适的入口，处理得更快：
>
> - **某条下载链接失效：** 点击资源卡片上的「报告失效」。
> - **需要网站管理员修改数据**（改条目、改账号、处理违规等）：在工作台[「问题处理」](/workspace/issues)提交站务反馈。
> - **想分享游戏或补丁资源：** 到对应游戏的资源区「添加资源」，审核通过后再把资源卡片的分享链接贴进回答。

## 发帖前

发帖前先搜一搜。发帖页会根据标题和关联的游戏列出相似求助，已有的回答也许就能解决你的问题。

发帖时必须选一个分类：

| 分类 | 适合发什么 |
| --- | --- |
| 求游戏或资源 | 站内还没有的游戏、补丁、资料集，或站外的工具、字体等 |
| 运行问题 | 区域语言、运行库、兼容性、字体显示、启动失败、乱码、存档 |
| 下载与解压 | 网盘客户端、网络、分卷、校验、解压软件与密码格式 |
| 账号与站务 | 登录、验证、萌萌点规则、投稿流程等疑问 |
| 求推荐 | 求推荐游戏、找忘了名字的游戏；已经知道是哪部游戏、想要下载或补丁的，请发到「求游戏或资源」 |
| 其他 | 以上都不适用的社区问题 |

问题和某部游戏有关时，可以关联站内的游戏条目。站内还没有这部游戏时，可以填游戏名，并附上 VNDB、Bangumi、Steam、官网等资料链接（最多 5 个），方便回答者确认是哪部游戏。

## 怎样写一条容易被回答的求助

- **标题直接写问题。** 例如「某某游戏启动后黑屏」，比「求助！！」更容易被会的人看到。
- **写清楚环境和已经试过的办法。** 系统版本、区域设置、报错原文、做过哪些尝试，都能帮回答者少问一轮。
- **配上截图。** 帖子和回答都可以上传图片：点编辑器的「上传图片」选择，或者直接把图片拖进编辑器。支持 JPG、PNG、WebP、AVIF，单张 8 MB 以内，每条最多 6 张。
- **注意个人信息。** 截图和正文里不要露出账号、密码、邮箱、真实姓名等信息。写错了随时可以编辑删掉。

## 费用与奖励

| 规则 | 内容 |
| --- | --- |
| 发帖费 | 每条 **5 萌萌点**，发布成功才扣，失败不扣。发布后删帖、被隐藏或没人回答，都不退 |
| 每日上限 | 每人每天最多发 **3 条** |
| 采纳奖励 | 每条求助第一次采纳合格回答时，系统给回答者 **3 萌萌点**。之后改选或取消采纳，奖励不转移、不收回 |
| 奖励条件 | 提问者和回答者都要注册满 7 天；每人每天最多获得 3 次采纳奖励。不满足条件时只记采纳，不发萌萌点 |

萌萌点不够时，可以先[每日签到](/doc/notice/moemoepoint)获得萌萌点。回答本身不需要萌萌点。

## 回答、采纳与关注

- **回答：** 登录后可以回答任何人的求助。回答里可以直接写站外链接；分享游戏或补丁资源时，推荐贴站内资源卡片的分享链接。
- **回复：** 每条回答下面可以回复，用来追问或补充，只能写纯文字，最多 1000 字。
- **有用：** 觉得别人的回答有帮助，可以点「有用」，回答会排得更靠前。点「有用」不发萌萌点。
- **采纳：** 问题解决后，请采纳帮到你的那条回答，帖子会变为「已解决」，也让后来的人知道哪个办法有效。之后可以改选，也可以取消采纳。自己的回答不能被采纳。
- **关注此帖：** 遇到同样的问题时，点「关注此帖」，不用重复发帖。有新回答和帖子解决时，你会在通知中心收到消息。

帖子不会因为长时间没人回答而关闭，任何时候都可以继续回答。

## 编辑与删除

自己的帖子、回答和回复随时可以编辑。删除有以下限制，因为别人已经花时间回答了：

| 内容 | 什么时候可以删 |
| --- | --- |
| 求助帖 | 还没有别人回答时。已有别人的回答后不能删，可以编辑；确实需要删除（例如误贴了隐私）时，请联系网站管理员 |
| 回答 | 没有被采纳时。已被采纳的回答要等提问者取消或改选后才能删 |
| 回复 | 任何时候 |

## 举报与处理

看到违规的帖子、回答或回复时，登录后点击内容旁边的「举报」，填写原因后提交。举报会交给网站管理员复核，进度可以在[问题处理](/issue)查看。不能举报自己发布的内容。

同一条内容被 **3 名注册满 7 天的不同用户**举报后，会暂时自动隐藏，等待网站管理员复核。暂时隐藏不等于判定违规。复核后：

- **确认违规：** 内容保持隐藏。
- **判定不成立：** 内容恢复显示，之前的举报不再触发自动隐藏。

内容被隐藏或恢复时，作者都会收到站内通知。帖子被隐藏期间，提问者自己仍能看到，其他人不能再回答。被隐藏的帖子不退发帖费。

## 内容规范

求助区的帖子和回答对所有访客公开，请遵守[《OtoAme 用户协议以及隐私政策》](/doc/notice/privacy)：

- 不公开他人的个人信息。
- 不发广告、引流或与问题无关的内容。
- 回答请对症，不确定的办法请说明「未验证」，不要为了回答而回答。
- 关联成人向（NSFW）游戏的帖子，只对开启了 NSFW 显示的用户可见。正文里请不要直接发布成人向图片。

情节严重或多次违规的账号，将按用户协议处理。
