# OtoAme

OtoAme 是乙女游戏文化社区，提供游戏介绍、截图画廊、资源分享、评论评价、条目投稿、问题反馈和私聊。发布者在个人工作台维护本人内容，管理员在后台审核投稿并处理社区事务。

从[维护文档导航](docs/README.md)按任务进入：了解全局可读[架构与职责](docs/project/overview.md)，本地运行可读[开发指南](docs/project/development.md)，上线与恢复可读[部署指南](docs/project/deployment.md)。这些说明描述仓库实现；目标站点是否已经启用某项能力，需要结合实际版本、迁移和配置确认。
