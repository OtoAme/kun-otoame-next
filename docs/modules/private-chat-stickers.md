# 私聊贴纸与目录维护

贴纸是独立的私聊消息，不从普通文字中的占位符解析。当前只开放已启用的内置贴纸包，免费使用，不开放用户上传、购买或支付。以后启用非内置包需要另行设计所有权与付费授权，不能因为数据结构已经存在就开放发送。

## 用户看到什么

发送时服务器重新确认贴纸存在且当前可用，不接受浏览器自行提供的资源地址。禁用贴纸或贴纸包后不再允许新发送，但保留目录、文件与历史消息。消息引用无法解析或缺少可用地址时，外层消息显示普通气泡中的「[贴纸不可用]」；正常贴纸直接展示媒体，并保留时间、已读和回复等交互。

动态贴纸播放前显示静态预览，视频首帧就绪后移除预览。消息里的媒体加载错误和无法解析贴纸引用是不同情况：有预览时可保留预览，无法展示媒体与预览时显示不可用。减少动态效果偏好使用静态预览；离开可视范围会移除消息的视频节点，返回时不保证续播原进度。

选择面板、回复预览和管理网格中的动态缩略图使用另一套可见性处理：首次加载后保留节点，离屏暂停、可见时继续。贴纸包封面始终使用静态预览。不能将缩略图行为套用于聊天消息本身。

移动端选择面板限制在消息可视区底部，不覆盖标题或输入区，宽屏以消息窗口确定大小与对齐。具体手机、键盘和媒体验收按[前端要求](frontend-content.md)检查，不能把设计要求当成所有浏览器已经通过。

## 素材限制

| 素材 | 当前限制 |
| --- | --- |
| 静态贴纸 | WebP，宽高均不超过 512 像素，最多 512 KB。 |
| 动态贴纸 | 带透明通道、无音频的 VP9 WebM，最长 3 秒，估算总帧不超过 100，最长边 512 像素，最多 300 KB，超限拒绝而非自动压缩。 |
| 动态预览 | 配套静态 WebP，首帧生成或由审核素材指定；封面不播放视频。 |
| ZIP | 单个最多 32 MiB，单次导入与解压总量最多 64 MiB。 |

导入校验真实文件类型，不只相信扩展名或浏览器类型。ZIP 拒绝路径穿越、盘符、网络绝对路径、符号链接、加密条目、解压炸弹和重复内容；仅把单个前导斜线的导出根目录转换成相对目录。新素材制作仍建议不超过每秒 30 帧，导入器不把根据旧导出时间戳推算的名义帧率当成严格拒绝依据。

贴纸文件设置一年缓存。后台导入的贴纸标识与动态预览地址包含内容摘要，更换素材会产生新地址。清单同步不同：素材与封面按包标识和贴纸标识存放在固定地址，同一标识换文件后会原地覆盖，而已缓存的旧文件不会立即更新；同步更换素材应使用新的贴纸标识。目录保存文件位置，由配置派生访问地址，不把旧域名当成唯一事实。

## 导入和同步操作

前提是操作者为管理员，已完成[贴纸结构迁移](operations.md#按能力选择迁移)，对象存储和图床正确配置，素材经过授权，动态素材处理工具可用。此处操作会写入目录和存储，不能在只有静态审阅授权的任务执行。

1. 在旧后台贴纸管理创建或选择内置包。新建包默认禁用；填写名称和描述，创建标识使用小写下划线格式，创建后不能改标识。
2. 导入单文件、多文件或 ZIP，查看逐文件结果；失败保留原因供纠正。数据库保存失败会尝试清理本次已上传对象，不能只看上传进度认定目录已更新。
3. 选择同一包内的有效贴纸作为封面。启用至少需要一张有效贴纸，显式封面也必须有效且属于本包；首张有效导入会成为默认封面。
4. 保存设置并启用，使用受控私聊验证选择、发送、历史与预览。切换包前处理未保存修改，不把关闭页面当作已保存。

批量素材也可用本地清单同步。先按[同步器的清单定义](../../scripts/syncStickers.ts)准备受控清单与相对资源文件，配置包的稳定标识、名称、说明、封面、内置与启用设置，以及每张贴纸的稳定标识、文件、替代文字和顺序；动态预览可额外指定。同步器接受字母、数字、下划线和连字符，包标识建议与后台一致使用小写下划线格式；贴纸标识全局稳定唯一。清单不存用户登录凭据。

将下列路径换成实际清单，先校验并审阅计划。预览不检查贴纸标识是否已属于其他包，这项冲突只在正式执行时拒绝：

```bash
pnpm stickers:sync -- --manifest=<本地清单绝对路径>
```

确认目标和预览无误后执行：

```bash
pnpm stickers:sync -- --manifest=<同一清单绝对路径> --apply
```

不指定资源根目录时使用清单所在目录，可用 `--root=<资源绝对目录>` 明确指定。同步上传并更新目录，不删除旧贴纸或文件。包的启用状态、内置标记与价格按清单写入，未填时贴纸包为启用；清单中的每张贴纸都会被设为启用，后台已禁用的贴纸重新同步后会恢复可发送。同步写入不经过后台的「启用需要有效封面」检查。要保留禁用状态，须从清单移除该贴纸或在同步后重新禁用。成功后仍需核对包状态和发送资格。失败按文件原因修正并重新预览，不擅自改变已有标识制造重复。

## 禁用、删除和清理失败

长期不再发送的素材先禁用，历史仍可展示。永久删除只用于误导入：须先禁用待删贴纸所在的贴纸包，单张贴纸本身不要求先禁用；被消息或回复引用的贴纸只能禁用，有用户所有权记录的包也不能删除。

确认删除后先提交数据库删除，再尝试清理文件。对象清理失败不恢复数据库，界面返回失败数量并提示删除已完成、资源清理不完整，服务端保留错误供人工核查。没有据此建立持久重试任务，不承诺自动重试或把已完成删除显示为完全失败。
