# 产品需求概要

状态：后续需求概要，具体范围与交互尚需细化；本文不表示功能已经实现。目标是完善用户使用流程、促进社区互助，并减轻站方日常处理负担。当前实现与规则见[业务参考索引](README.md)。

## 需求

| 方向 | 简要需求 |
| --- | --- |
| 首页 | 增加「最新求助」「最新评论」栏目，展示社区动态。 |
| 条目纠错 | 提供用户提交条目信息修正、站方审核并生效的流程。 |
| 管理后台 | 结合实际管理任务继续完善，减少重复操作和页面切换。 |
| 用户工作台 | 从使用者角度完善入口、内容组织和操作流程，方便管理本人内容及跟进相关问题。 |
| 事项系统 | 优化问题分流、处理责任、升级与结案流程，减轻站方负担。 |
| 旧后台退役 | 确认所需功能已有可用替代后，弃用并移除旧后台；明确旧地址与历史链接的承接方式。 |
| 运行问题与求资源 | 评估将这两类问题的提交入口迁至求助区，明确与资源缺陷、链接失效及站务事项的边界。 |
| 条目内求助 | 考虑在关联游戏条目中展示相关求助，方便查找已有答案和发起关联提问。 |

## 待明确

- 运行问题与求资源是否迁移，以及收费、无人回应和历史事项的处理方式。
- 用户工作台面向的使用者及需要集中展示的内容。
- 条目纠错的字段范围和审核规则，后台完善的具体问题与退役条件。
- 首页栏目的布局与展示规则，条目内求助的位置及其与讨论版的分工。

后续按确认后的需求补充验收条件与实施安排；未重新确认的历史设计不自动成为本轮要求。
