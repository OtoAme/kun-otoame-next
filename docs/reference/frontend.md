# 前端、编辑与内容展示

前端负责让用户理解当前内容、费用、权限和操作结果。服务器仍决定真实授权与保存状态；前端隐藏按钮、完成动画或成功提示不能替代服务器检查。页面分工见[页面边界](pages.md)，业务金额和时限见[业务规则](permissions.md)。

## 两套界面如何共存

前台、旧后台和管理员预览使用 HeroUI v2；工作台与新后台使用 shadcn，分别加载根布局、组件与样式。管理员预览使用独立根布局加载前台样式和公开卡片，不加载前台导航、页脚、小喇叭、实时消息和分析脚本。新后台不导入旧后台界面或前台主题脚本。两套界面共享深浅色选择，前台品牌主题的颜色规则由[主题说明](theme.md)维护。

工作台身份来自服务器会话，不能用浏览器保存的旧用户资料推断权限。公开页顶栏在本地没有登录资料时，仍向服务器确认当前会话。没有会话就保持访客；已登录但缓存为空时，反馈使用恢复后的账号。浏览器里已经记住的账号若会话失效，经过[统一身份确认与清理](../concepts/data-consistency.md#会话与浏览器状态)后退出；登录、两步验证、注册与退出共用认证操作协调，等待实际响应后提交本地身份。后台操作沿用现有管理接口，不能另设绕过同一授权的写入渠道。

## 账号偏好交互

账号首次选择内容显示或导入本机旧选择时，先修改草稿，再由用户确认保存。账号已经保存内容显示后，顶栏菜单和设置页每次选择都会立即保存这一项，成功后应用服务器返回的结果，其他设置的草稿继续保留。保存期间暂停重复选择，顶栏菜单保持文字与图标单行对齐，设置页显示保存进度。标签屏蔽、邮件通知和站内通知订阅分别保存或放弃各自草稿，操作范围限定在对应设置卡片。

界面等待当前身份和服务器快照确认后才允许编辑。保存失败保留输入并提供手动重试，恢复连接不自动重放。冲突展示服务器结果，用户可以采用该结果，或明确保留自己的选择后再次保存；内容显示的冲突处理只影响该项。后台取得新快照时保留尚未保存的草稿，切换账号或建立新会话时隔离旧输入。

账号尚未选择内容显示时按 SFW 展示，并提供明确选择和本机旧选择的首次导入。首页最新游戏和最新补丁直接展示统一的公开 SFW 首屏。个性化列表按当前身份、筛选与浏览条件复用服务器首屏，同一条件的再次确认保留现有内容，条件变化后的旧结果不会回填。偏好同步复用[消息摘要策略](../concepts/performance.md#实时统计与公开消息)，不额外启动持续轮询。

## 组件选择与复用

修改 UI 默认沿用原有设计，包括尺寸、间距、配色、对齐、信息层级和交互方式。需要改变既有设计时，实施前向用户说明具体变化、原因和影响范围，并遵循用户已经明确的调整要求。

编写或调整 UI 前，先查目标页面、共享组件和同一界面体系下的同类页面实现。查找范围包括组件组合、布局和状态展示，例如分页与每页数量选择、筛选与操作按钮、侧栏及空状态。有满足需求的实现时，直接复用组件并沿用已有组合方式与样式约定。恢复旧版设计时，先核对相关组件的 Git 历史，以源码中的结构和样式为依据，截图用于核对实际显示结果。

界面按以下顺序选择组件与组合方式。

1. 与该界面体系一致的仓库业务组件、基础组件及同类页面组合。工作台与新后台先查 shadcn 基础组件及控制台业务组件，前台、旧后台与预览先查前台共享组件及已有 HeroUI v2 用法。[前台共享组件](../../components/kun/)、[shadcn 基础组件](../../components/dashboard/ui/)、[控制台业务组件](../../components/dashboard/)
2. 对应 UI 库的官方组件及组合用法。本地缺少适用实现时，核对官方组件能力，按项目现有配置与样式边界补入或使用，复杂交互优先组合现有组件。
3. 现有组件、官方组件及其组合都无法满足具体需求时，才自行实现。

按钮、表单、选择器、菜单、标签页、弹窗、抽屉、卡片和标签等都按上述顺序选择，不为实现方便或局部外观改用浏览器原生控件、系统确认框或手写 HTML/CSS 重建已有能力。普通语义结构和布局样式可以按需编写，有同类布局时沿用其结构与样式约定。使用或组合组件时，保留官方语义及标签、错误、键盘、焦点、禁用、加载和弹窗关闭行为。

## 提交、冲突与请求失败

用户名与签名设置预填已保存资料，仅在去掉首尾空格后有合法修改时允许保存。资料异步刷新时，尚未编辑的字段跟随最新资料，已经输入的草稿保持不变。其他表单和请求的开发要求是：业务错误显示具体安全原因，释放加载状态并保留可重试内容，过期响应不覆盖新筛选、新目标和新保存结果。

新增游戏评价需要指定游戏；编辑现有评价时保留原作者和所属游戏，只更新评价内容。保存期间防止重复提交，业务拒绝或网络失败均保留输入并允许重试；成功后用服务器返回的已保存记录更新评价卡片。

删除、审核、资源处置、对话隐藏等交互的开发要求是先确认再发送写请求，取消不写入，关闭后恢复触发位置的焦点。提交中的确认界面按具体流程锁定，避免重复提交或用户误以为已经取消；验收需检查本次受影响入口。管理员发放结果未知时固定原请求，只重试原内容或先查账；不能换金额后沿用原请求。

资源编辑保留打开时的完整链接和地址版本作为比较记录，保存冲突保留草稿与该记录，不自动合并或覆盖。问题处理页资源盘链接失效的补链进入既有受权编辑页，不通过下载获取来取得管理资料。具体本人编辑与维护见[工作台](workspace.md)。

资源合并工作台的合并动作只能基于当前有效预览，选中或推荐一张站方卡片不等于已确认同一内容。工作台够宽时用户资源与官方资源分成两栏，中间分开，两栏各自滚动，便于对照卡片；不够宽时上下排列、整栏滚动。官方资源上的匹配项命中为绿色、未命中为红色，并保留对号和叉号文字。候选、预览与写入响应分别核对目标身份，迟到响应不覆盖新选择；单对合并后保留结果条，批量按对显示结果和缓存重试，不让旧目标的结果控制新选择。批量清单只存当前标签页的会话存储，不冒充服务端队列；结果面板不随清单跨刷新恢复。管理员只读预览可显示链接地址，不另返回提取码或解压码字段，也不执行获取、恢复、点赞和编辑。完整规则见[站方备份与存量合并](permissions.md#站方备份与存量合并)。

## 下载与反馈的展示

资源卡片先展示安全概况，用户主动获取后才在当前界面内存显示真实地址、提取码和解压码，不能写入全局状态、持久存储或网址。刷新恢复只填回已经打开、当前仍有效的镜像，未点过的镜像继续隐藏；资源授权不代表所有镜像已经揭示。

每条链接分别呈现可用状态、机器观察和反馈人数。健康圆点旁保留文字，详细观察放在可访问的提示中。机器无法判断时不提示检测成功，也不删除既有健康结论。失效链接可以折叠，但仍可展开、获取和在两步问题入口中选择；不按健康重新排列整份资源。

下载地址与密码应可复制、换行且适应窄屏；链接所在行的空白不承担跳转。下载、编辑、检测、核实和举报依服务器给出的当前能力呈现，当前地址或读取结果改变后丢弃旧凭据和迟到回调。管理员只读预览跳过下载获取、恢复和点赞写入。

资源问题先选择整份资源或具体链接，再选择现象。下载慢提供指南，单链接失效走链接报告；资源发错条目交管理员，其他问题按[反馈分工](permissions.md#反馈与处理)处理。游戏反馈中的资源失效和发错条目只引导到资源区，不创建事项；求资源或催更按选中的游戏或资源确定处理方，不承诺游戏级反馈的首次响应期限。

## 问题处理与后台队列

用户问题页展示本人提交、待处理和关注的事项；后台问题处理页处理站方问题与资源盘链接失效，并有发布者处理中只读视图。可见对话与署名由服务器提供，不因头像或用户不是开启者就推断其身份。目标被删后保留历史对话，停用失效目标链接和依赖现存目标的动作，人工结案需说明。控制台与用户问题页的附图可点击选择、拖入或粘贴，在回复框里粘贴截图也会作为附图上传，数量上限与上传规则不变；对话中的附图点击后在站内共用灯箱中放大，可缩放、切换同一条消息的附图和下载，按住修饰键点击仍在新标签页打开。

筛选、搜索与排序保存在网址，切换视图或搜索按规则回到首屏。加载或失败不能冒充零条。收件箱只在事项离开队列时移除该行；普通回复或业务失败在原详情中刷新，保留错误和未提交输入。手机列表与详情保持主要操作可达，桌面分栏可恢复已保存宽度。

## 投稿的编辑与预览

草稿与要求修改可以编辑，其他状态只读，包括外部资料抓取和回填控件。自动保存按顺序执行，真正的跨设备冲突停止后续保存；显式保存、提交或可编辑预览都等待保存成功。待审预览直接读取已冻结版本，发现错误需先撤回。

尚未上传的裁剪封面在保存或提交前提示上传、跳过或取消；上传失败保持当前上下文。截图选择和拖入只进入浏览器暂存，点击上传后才传到服务器。上传期间可以继续加入下一批；失败与刷新中断保留重试所需文件，服务端确认成功才移除本地项，不能以字节百分比描述文件数进度。

截图排序与本地暂存共同恢复，保存、上传、预览和提交前需要同步顺序；失败停止后续动作并保留排序。读取本地素材未完成、仍有失败或待传内容时不开放提交。切换投稿后，在途任务仍归原投稿，不改写新目标的界面。选择、放大、删除和拖动手柄要能用键盘操作，手机只在拖动手柄上接管手势，其他区域仍可滚动。

作者预览与审核使用正式条目外观，只显示已保存内容。会社解析歧义对作者给中性提示，管理详情提供受权诊断；客户端不能补查受限候选或原始身份。审核动作都在详情中确认，快捷键与鼠标一致。共享 VNDB 作品编号仍需作者确认、审核员判断；具体押金、名额、重复规则归[投稿规则](permissions.md#内容发布与投稿)。

## 正式条目编辑与截图

外部资料来自多个异步来源，合并时只更新该来源负责的内容，不能用旧快照覆盖其他来源。Bangumi 标题和简介由用户主动填入，不自动覆盖已有文字；VNDB 不导入标签。Steam 重复只提示，硬重复拒绝，会社来源随受控解析配置一起切换。

创建主体成功而截图部分失败时保留已创建目标和本地图片，重试只补失败项。重写页的失败新图仅在当前编辑会话中保留，重新进入编辑应建立新会话，避免把上个目标素材带入下一条游戏。封面列表小图、详情图和灯箱原图要共同更新；清缓存不能替代实际上传原图。

静态截图可按选择加水印，动画原图保留且不加水印。列表优先缩略图，灯箱与下载使用原图；未生成缩略图时允许退回原图。缩略图加载后可能开始低优先级预载原图，灯箱另预载相邻图片，不能承诺列表绝不请求原图。成人内容遮罩与放大入口同时遵守分级限制。

## 通知、私聊与贴纸

消息导航区先排列消息与私聊入口，分隔线下方展示带图标的通知分类。分类选中项使用主题强调色的浅底与文字色，普通项无底色。宽屏时在左侧纵向排列，窄屏时分类横向滚动。分类旁仅在有未读通知时显示数量，「全部分类」显示未读总数，切换阅读状态时也按这一口径显示。阅读状态在通知列表上方使用标签页切换。

通知首屏在当前身份确认后读取一次，重复初始化共用在途请求。主动切换分类、阅读状态或每页数量开始新一轮查询，并通过浏览器历史记录更新地址。每页数量默认为 20 条，可选择 10、20、30 条，改变数量后从第一页开始。前进后退按分类、阅读状态和每页数量恢复对应的已加载视图。同身份摘要、订阅或浏览偏好变化保留正在显示的通知卡片，新内容由用户点击提示后读取。

「全部分类」的卡片标注所属分类；进入子分类后，卡片只标注事件名称。通知中的评论摘录和回复支持安全的 Markdown 格式，包括强调、代码和站内提及链接。代码按文本展示，其余通知文案按纯文本显示。引用区只显示能够识别的填写内容，例如评论摘录、审核理由或管理员手写的公告。新评论回复把原评论的空白压成一行，摘取前 107 个 Unicode 字符，超出时加省略号，再在「TA 的回复内容」下引用对方的回复，超出通知长度上限时可打开详情阅读。历史通知仅包含原评论时继续显示原有摘录。反馈原因和处理回复分别引用，字段标签、自动生成的变更摘要和默认处理留言用普通文本显示。无法辨认填写范围的历史通知按普通文本完整展示。正文和引用区可以点选、复制。点击卡片的空白处可打开详情，发送者头像和正文展开按钮可单独操作。

列表卡片与详情目标等待共享显示边界就绪，会话或个性化内容刷新期间暂停观察，恢复后重新累计阅读时间。页面可见且卡片有实际露出的区域，连续约 1 秒后提交该条的已读确认，折叠长文也适用。整条通知正文超过 350 个 UTF-16 码元或超过 8 行时默认显示前 5 行。滚动时卡片持续可见就继续计时，移出视口、完全遮挡或页面进入后台后重新计时。点击「展开完整正文」立即提交该条确认，按钮可用键盘操作。自动确认发送前再次检查当前身份、页面和可见资格，失去资格的排队项重新观察。合法请求已经发出后可以完成，旧页面和旧身份的结果不能污染当前界面。详情入口在目标成功展示、获得焦点并持续可见后核对入口关系，只确认入口那一条，直接访问、预取和失败加载不确认。跨标签的入口元数据只在内存交接。

铃铛存在通知未读时默认打开「全部分类 · 未读」，显式分类和阅读状态链接优先，私聊未读独立。七类通知与未读、全部、已读可分别切换。旧提及、关注和系统入口分别打开「@与回复」「关注动态」和「官方消息」。未读以本轮编号上界和递减游标前后翻页，全部与已读使用页码。自动确认和展开确认的卡片原位保留。分类与页面缓存仅在当前授权身份的内存保存，返回时等待当前内容成功显示后恢复位置。同一会话暂时待确认或不可用时隐藏并保留缓存，恢复后继续原页。导航离开与内容隐藏期间不改写已保存的位置。退出、账号、会话上下文或代数实际变化时清除。

「未读」和「全部」视图提供「全部已读」，作用于当前分类的所有分页，「全部分类」作用于全部分类。成功后同步摘要，并重新读取受影响的当前列表，相关分类及合并视图的旧缓存失效。失败保留列表并允许用户再次点击。清理仍在独立的「已读」视图中执行。

通知与私聊红点分别更新。顶栏、消息导航与会话恢复共用全站摘要；会话恢复取得合法摘要后，直接复用结果。摘要只更新计数和新动态提示，不重排已展示列表或替换其内容基准；用户点击新动态提示后读取新内容。摘要缺失或同步失败保留已有红点和最近成功时间；确认零未读才清除相应状态。列表错误与成功空结果分别显示，确认失败保留未读并提示刷新页面后重试。空列表使用共用插画与提示文案，未读空列表提供查看全部通知的入口。未读列表在有上一页或下一页时显示分页。清理入口位于「已读」视图，全部分类下显示「清理全部已读」，具体分类下显示「清理已读」。确认窗口说明清理范围，取消不写入。

全站摘要约每 60 秒读取，会话列表每 30 秒读取。隐藏、离线或身份未确认时暂停；普通页面连续 5 分钟无点击、输入、滚动或触摸也暂停，前台私聊详情持续同步摘要。恢复事件合并，在途请求去重，失败后保留内容并提示等待自动重试；具体等待规则见[消息同步性能策略](../concepts/performance.md#消息同步)。会话列表当前页没有未读，只更新该页，不能清除其他页的全局私聊红点。

私聊首屏取编号最大的最近 50 条并升序展示，历史上翻独立读取；正常同步合并新增消息和已有消息复核。复核覆盖可见消息、灯箱图片所属消息、回复草稿目标及可见引用目标，优先当前操作，每批最多 100 个去重编号，超过后继续有界分批。只有成功合入的新增批次推进新增游标；历史、复核和范围已读保持独立。正在阅读历史时保持阅读位置，不强制滚到最底。

编辑结果更新当前内容和引用预览；删除或不可用结果清除正文、媒体、灯箱、引用缓存和回复草稿，迟到响应不能复活已删除内容。私聊第一次展示时，页面与浏览器须确认属于同一次登录。已打开的对话在另一标签页退出或换号后停在原处，保留阅读位置、未发文字和所选图片，暂停读取、上传、发送和已读。原账号重新登录并通过原对话成员检查后，可以从原处继续，由用户主动发送。刷新或重新打开时按当时的身份读取。

对话已展示且处于前台时才确认历史对方未读。详情请求绑定编辑时的会话，旧响应不能追加新消息、清空原稿或触发上传后的发送。

输入法确认候选时不发送，普通回车发送，组合换行键保留换行。单次最多 9 张图片，部分上传成功后重试只补失败项；失败后增加或删除图片不能丢掉未变图片的已上传登记。

回复可经鼠标菜单、键盘菜单或手机滑动进入，图片回复标明所选图片；引用预览可定位原消息并提供返回位置。移除私聊的确认说明只影响本人列表。贴纸目录、动态媒体与失效降级归[私聊贴纸说明](stickers.md)。

## 小喇叭、账目与内容渲染

小喇叭各公开入口共享读取逻辑，但按账号、分级和屏蔽偏好隔离结果；切换身份不能沿用另一身份的占位内容。失败保留仍可展示的旧消息，并显示重试；临近官方时间边界时不继续展示不确定的置顶或到期横幅。官方移除与提前结束的确认说明分别表达其公开历史结果。

账目同时显示总额、待结算和可用额，负余额如实显示并说明奖励回退；管理员看他人明细不覆盖自己的顶栏余额。自定义日期尚未查询时不继续展示旧范围记录。金额规则归[账务说明](permissions.md#萌萌点账务与资料修改)。

网站文章、游戏简介、评论、资源备注与编辑预览按单次换行展示换行，并通过相应内容清理避免不受信内容成为可执行页面。线上文章源与仓库维护文档分开，构建需携带文章和运行资源。修改编辑器应同时检查图片、链接、视频、提及和预览。

## 前端验收要求

移动端和可访问性是变更要求，不能当成全站已完成测试的结论。相关页面至少检查约 360 像素手机与桌面，布局经过平板断点时也检查该区间；覆盖长文字、长链接、媒体、虚拟键盘、菜单、弹窗、焦点、错误与减少动态效果。只跑类型检查和组件测试不能证明真实浏览器布局正确，具体命令归[测试指南](../guides/testing.md)。
