# 业务规则与参考索引

本目录的页面供查证具体规则：谁可以操作、需要什么条件、结果和限制是什么。系统整体怎样运转见[原理说明](../README.md#原理说明)，具体操作步骤见[操作指南](../README.md#操作指南)；规则涉及的迁移、清理与回填只在[运维指南](../guides/operations.md)维护步骤。

## 规则页怎样衔接

一项功能通常要连续查阅几页。先在[页面与访问边界](pages.md)找到用户从哪里进入，再读[权限与业务规则](permissions.md)判断能否操作、收费和时限。涉及保存、下载凭据或文件失败时，继续读[数据、缓存与上传一致性](../concepts/data-consistency.md)。页面显示与交互要求归[前端与内容](frontend.md)，颜色含义归[主题与颜色](theme.md)。

[用户工作台与链接维护](workspace.md)贯穿本人权限、资源编辑、用户反馈和健康处理；[私聊贴纸](stickers.md)贯穿目录管理、发送资格与媒体展示。它们引用公共业务规则，不另建一套授权或费用规则。

[数据库索引](database-indexes.md)说明索引承担的查询与去重职责。[已知代码问题](known-issues.md)记录实现与预期不一致之处；规则页按实际行为描述，并链接到对应条目。

## 从规则到源码

每页末尾的源码入口给出精确追溯位置。修改前按[技能分工](../../skills/README.md)读取对应技能及必读文档；规则页维护业务含义，源码链接只提供追溯，不能代替正文解释。
